# iOS sideload shell — plan

> For agentic workers: executed inline (superpowers:executing-plans). Spec: `docs/superpowers/specs/2026-11-18-ios-shell-design.md`.

**Global constraints:** iOS 17+. Bundle id `com.habbi95.guitarchords`. No third-party runtime code. The web app's files are bundled unchanged. CI must stay green on every push to `main`.

**Review focus:**
1. A path traversal request (`app://localhost/../x`) must not read outside the bundle.
2. `prompt()` must work natively.
3. localStorage must persist across launches. Manual check on the device.
4. The screen must not auto-lock while the app is open. Manual check.
5. An unknown file extension must still be served with a safe MIME type.

### Task 1: Repo hygiene and web tests in CI
Normal `.gitignore` (the whitelist was only for the home-dir repo): `node_modules/`, `.superpowers/`, `ios/web/`, `ios/*.xcodeproj/`, `build/`, `*.ipa`, `.DS_Store`. README with install steps. Workflow job `web` runs `node --test`. Verify: the push shows `web` green with `gh run view`.

### Task 2: WebShellKit (TDD on CI)
`public enum WebFiles { static func resolve(_ url: URL, root: URL) -> (file: URL, mime: String)?; static func mimeType(forExtension: String) -> String }`. Tests:
- `index.html` gives `text/html`; `.js` gives `text/javascript`; `.css` gives `text/css`; `.png` gives `image/png`; `.webmanifest` gives `application/manifest+json`; unknown gives `application/octet-stream`.
- An empty path or `/` resolves to `index.html`.
- `../secret`, `/js/../../x` and percent-encoded `%2e%2e/` return nil.
- A query string is ignored.

Workflow job `swift` runs `swift test --package-path ios/WebShellKit`. Watch it go RED (stub) and then GREEN.

### Task 3: App shell + IPA build
- `ios/App/*.swift`: `GuitarChordsApp`, `WebView` (UIViewRepresentable with the scheme handler and UIDelegate prompt), `SchemeHandler`.
- `ios/App/Assets.xcassets/AppIcon` with a 1024 px icon (extend `tools/make-icons.py`).
- `ios/project.yml`.
- Workflow job `ios` on `macos-latest` (needs `web` and `swift`): copy the web files into `ios/web`, `brew install xcodegen`, generate, build, package `GuitarChords.ipa`, upload the artifact.
- Verify: the run is green and the artifact contains `Payload/GuitarChords.app` with `web/index.html` inside.

### Task 4: Handoff
Final review, Sideloadly steps for the owner, and the iPhone checks: prompt works, data persists after a restart, the screen stays on, it plays with the silent switch on.
